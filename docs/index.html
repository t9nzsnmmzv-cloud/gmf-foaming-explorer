V0.3 · 收集罐与消音器连接

  1. 原料从高压釜顶部向下接入。
  2. 物料收集罐位于两台高压釜正下方，釜底管道分别接入罐顶。
  3. 收集罐上端独立管道连接消音器。
  4. 收集罐底部落料由输送机正下方接料段承接。
  5. 风机安装于颗粒后处理装置顶部。
  6. 后处理通过开放料斗从上方接入筛分装置。

模型依据官方宣传页第3页、装配体1的外观参考，以及你确认的连接关系。现有版本为300L×2示例机组，非报价方案中的1.4m³整线。比例、内部细节和接口尺寸仍需CAD图纸核对。
